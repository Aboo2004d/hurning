استُخدمت أدوات Chromium وPoppler وTesseract فعليًا على ملفات محلية، بما فيها بيانات العربية والإنجليزية. تستخدم اختبارات بوابات الدفع والنشر ردودًا وهمية؛ لم تخصم أموالًا أو تنشر محتوى أو ترسل رسائل حقيقية.

فحوص DTO تؤكد ترجمة استعلامات الخدمات إلى SQL، وتوافق نموذج EF مع migrations، وحدود البيانات المعروضة، وحقن الاعتمادات. يمنع interceptor فتح الاتصال بهذه الفحوص عمدًا.

## فحص المتصفح

نجح 134 تأكيدًا في Chromium، بالعربية والإنجليزية وعلى قياسات الهاتف واللوحي وسطح المكتب: عرض بطاقات DTO، فصل قسم الإغلاق قبل النتائج، بقاء شارة الجديد، RSS المطابق للبحث والفلاتر، صفحات العضو، ثماني شاشات إدارة، ظهور سبب توقف AI ووقت عودته، وطلب فحص الأداة عبر GET/fetch دون انتقال الصفحة. لم تُسجل أخطاء JavaScript.

صُححت مراجع الجزأين `_ClosingWeek` و`_AiPauseStatus` إلى مسارات Razor صريحة كي يمكن إعادة استخدامهما في معاينة شاشات أخرى.

## الحدود

- لم تُنفذ اختبارات التكامل مع SQL Server حقيقي: تعذر تنزيل SQL Server بسبب استجابة 403 من بيئة الشبكة. ترجمة SQL وتوافق النموذج لا يعوضان اختبار المعاملات والتزامن على قاعدة حقيقية.
- نجاح المحاكاة لا يثبت صلاحية مفاتيح الإنتاج أو صلاحيات الحسابات لدى المزودين؛ يلزم التحقق منها في بيئة المستخدم.
- لا توجد migrations أو تغييرات في إعدادات الربط ضمن هذه الدفعة.
- بقي التتبع العام وقوالب قنوات التليجرام والبوت مؤجلين لحين إذن المستخدم بعد الرفع.
