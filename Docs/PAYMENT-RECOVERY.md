# تسوية المدفوعات بعد الخصم

## منع التكرار

جوال باي يحجز ConfirmationStartedAt ويزيل مفتاح الجلسة المحفوظ قبل إرسال التأكيد. لا يعاد إرسال تأكيد محجوز، حتى عند غموض الرد. لحظة تحجز CheckoutStartedAt ومرجع الطلب قبل إنشاء جلسة البوابة. المفاتيح تخص طلب الدفع نفسه؛ إنشاء طلب آخر يمكن أن ينشئ دفعة مستقلة.

اعتماد الدفع وإنشاء الاشتراك ورسالة العضو وتدقيق الاعتماد يحفظان ضمن معاملة Serializable مع قفل العضو، وفهرس OrderId الفريد يمنع فترتين لنفس الطلب. نجاح الخصم عند المزود يقع خارج معاملة SQL؛ قد يسبق حفظ الاشتراك أو يتأخر إثباته.

## التحقق الآلي واليدوي

| المسار | السلوك |
| --- | --- |
| Webhook لحظة | يتحقق من التوقيع ثم يجدول استعلام API؛ لا يمنح اشتراكًا من الحمولة وحدها |
| فحص المشترك/الإدارة | يطابق مرجع الطلب والمبلغ والعملة والبيئة، ويمكنه إعادة فحص فشل سابق |
| العامل: لحظة | يختار الطلب الذي بدأ وله مرجع محفوظ، باستثناء Paid وCancelled، بما فيه Failed وManuallyApproved للتحقق المتأخر |
| العامل: جوال باي | يختار الطلب الذي حُجز تأكيده، باستثناء Paid وCancelled، ويقرأ الإيصال أو يستعلم عن المعاملة دون تأكيد OTP مجددًا |
| فشل SQL أو تحليل إيصال | يعزل العامل كل طلب؛ يمكن متابعة غيره، وتبقى إعادة الفحص متاحة |

يفحص العامل حتى خمسة طلبات في الجولة حسب أقدم تحقق. الفاصل للطلب في أول يوم خمس دقائق، ثم ساعة حتى نهاية الأسبوع الأول، ثم يوم للطلبات الأقدم. لا يحذف الطلب من الاستعادة لمجرد قدمه. هذه مواعيد أهلية وليست ضمان زمن إنجاز؛ التوقف وتراكم الطلبات وعدم جاهزية المزود يؤخرها.

الإدارة تجد مرشح «دفعات تحتاج تسوية» في قائمة المدفوعات، وعلامة وشرحًا في التفاصيل. العلامة تعني أن المحاولة بدأت ولم يعتمد نجاحها، ولا تثبت وحدها حصول خصم. الموافقة اليدوية تتطلب السبب والدليل كما كانت سابقًا؛ تحقق API بعد الموافقة لا يضيف فترة اشتراك ثانية.

## حدود جوال باي

إذا نجح الخصم ثم ضاع الرد قبل حفظ الإيصال، يحاول الإنتاج العثور على العملية عبر `/api/partner/transactions` ومطابقة external_ref والهاتف والمبلغ. إذا لم تعد العملية ضمن النتائج التي يعيدها API، لا يوجد في العقد الحالي endpoint موثق للاستعلام المباشر عنها بالمرجع؛ لم نختلق endpoint ولم نعد الخصم. يلزم دليل من البوابة ومراجعة إدارية، أو تزويد عقد رسمي للاستعلام الفردي/الصفحات/ويب هوك ليضاف مسار آلي آخر.

في Sandbox لا يوجد endpoint قائمة معاملات تجريبي ضمن العقد المتاح؛ الإيصال المحفوظ قابل للاستعادة، أما الإيصال المفقود فلا نعوضه باستعلام بيانات الإنتاج.

## حدود المراجعة

لم تنفذ دفعات أو اتصالات مزود أو اختبارات أو بناء. لا يوجد ضمان ذري بين خصم جهة خارجية وحفظ SQL؛ هذه آلية منع تكرار وتسوية، وليست ضمانًا بأن كل حالة ستعالج تلقائيًا دون تدخل.
