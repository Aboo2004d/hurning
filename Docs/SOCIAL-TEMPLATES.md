# قوالب النشر وإصداراتها

من الإدارة ← المحتوى والتواصل ← قوالب النشر، تتوفر قوالب Facebook وLinkedIn منفصلة. يبدأ النظام بعشرة قوالب محفوظة في قاعدة البيانات: قالب عام وأربعة أنواع لكل منصة. اختيار منصة ونوع من أعلى القائمة يفتح المحرر، بما فيه الأنواع التي قد تضاف إلى enum لاحقًا ولا تملك قالبًا بعد.

- كل حفظ ينشئ رقم إصدار جديدًا ويعتمده، داخل transaction وقفل SQL لكل منصة ونوع. يوجد فهرس فريد يمنع اعتماد إصدارين للنطاق نفسه. تحرير قديم من جلسة أخرى لا يستبدل الإصدار الجديد.
- الإصدارات السابقة غير قابلة لتعديل النص أو الحذف من التطبيق. الاستعادة تنسخ نص الإصدار القديم إلى إصدار جديد مع تسجيل منفذ العملية وتوقيتها؛ تبقى أرقام الإصدارات السابقة محفوظة.
- سجل الإصدارات مرقم بعشرة سجلات من الخادم، وأزرار التنقل تجلب العرض عبر fetch دون إعادة تحميل المحرر أو فقد نصه. الفشل يعود للتنقل العادي. الأوقات بتوقيت فلسطين.
- زر المتغير يدرج الرمز عند موضع المؤشر. المتغيرات: `{{kind}}`, `{{title}}`, `{{organization}}`, `{{location}}`, `{{deadline}}`, `{{summary}}`. يرفض الحفظ أسماء غير معروفة أو أقواسًا غير مكتملة.
- يمكن معاينة النص على معرّف فرصة حقيقية بطلب محمي بـCSRF دون حفظ أو نشر. تحميل نص إصدار قديم للمعاينة لا يعتمده؛ الاعتماد يحتاج حفظًا صريحًا.
- يحذف المحرك السطر الذي يتضمن قيمة فارغة، فلا يخمن موعدًا مفقودًا ولا يترك وصفًا بلا قيمة. نص بيانات الإعلان لا يعاد تفسيره كمتغيرات. يعرض Razor وtextContent المعاينة كنص.
- عند التجهيز يستخدم النظام الإصدار المعتمد للنوع إن وجد، وإلا القالب العام للمنصة نفسها، بما فيه الأنواع المستقبلية. النص قابل للتحرير، ويظل إصدار القالب الذي عُرض محفوظًا مع محاولة النشر حتى لو اعتمدت الإدارة إصدارًا أحدث أثناء التحرير.
- يضاف رابط الفرصة الأساسي على الخادم مرة واحدة في نهاية النص، ويُعرض منفصلًا في المعاينة. حدود المنصة وتأكيد إعادة النشر والاشتراطات الحالية تبقى مطبقة.
- المنشورات السابقة للترحيل لا يُنسب لها إصدار تخميني؛ TemplateVersionId فيها null.

## الترحيل والتحقق

Migration: `VersionedSocialTemplates`. ينشئ الجدول والفهارس والعلاقة ويضيف الإصدارات الافتراضية مرة واحدة. Web يطبق migrations عند بدء التشغيل. حدّث Web وWorker معًا. لا يتطلب إعداد مفاتيح جديدة ولا ينشر أي محتوى تلقائيًا.

```text
dotnet run --project tests/HiringPs.Checks -c Release -- --social-template-check
```

الفحوص المحلية تختبر المتغيرات والقيم الناقصة والأنواع المستقبلية وعدم إعادة تفسير قيم المصدر وثبات الإصدارات ومطابقة نموذج الترحيل. فحوص SQL مضافة إلى `--membership-sql-check` وتتطلب HIRING_TEST_SQL؛ تنشئ قاعدة مؤقتة للتحقق من الترحيل والاختيار والرجوع للقالب العام والحفظ والاستعادة وتعارض الجلسات. لا تستخدم مفاتيح منصات أو نشرًا حقيقيًا.
