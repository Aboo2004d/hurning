# مهمة مؤجلة: إعداد المصادر وجمعها تلقائيًا

تاريخ التسجيل: 2026-10-14
الحالة: بدأ تنفيذ مساعد إعداد مواقع المصادر بطلب المستخدم في 2026-10-16. تكامل المنصات الاجتماعية أدناه مؤجل للمرحلة الثانية.

## طلب المستخدم
إيجاد طريقة واضحة لإضافة مصدر جديد بحيث يكتشف المجمّع طريقة جمعه وإعداداته تلقائيًا، دون مطالبة المستخدم بفحص كل صفحة أو إدخال محددات CSS يدويًا. توضيح كيف سيعمل المصدر الجديد، وكيف نتحقق من جاهزيته وماذا يحدث إن تعذر جمعه.

## المطلوب عند العودة إلى المهمة
- توضيح الفرق بين إضافة موقع مصدر جديد وإضافة موصل جمع جديد في الكود.
- دراسة اكتشاف RSS أو API المتاح أو استخدام المتصفح للمحتوى الديناميكي، واختيار الطريقة المناسبة تلقائيًا عندما يكون ذلك ممكنًا.
- اقتراح اختبار أولي للمصدر قبل تفعيله: اكتشاف الروابط، استخراج عينة، التحقق من اكتمال المحتوى ومنع التكرار.
- عرض الطريقة التي اختارها النظام ونتيجة الاختبار والأخطاء بوضوح للمستخدم، مع مسار للمراجعة عند فشل الاكتشاف.
- توضيح حدود الأتمتة؛ لا يمكن ضمان عمل كل موقع دون مشاكل بسبب الحماية وتغير الصفحات واختلاف بنيتها.

## ترتيب العمل عند التأجيل الأول — توثيق تاريخي
كان المطلوب استكمال التحقق المحلي أولًا دون تعديل الكود ضمن تسجيل الملاحظة. طلب التنفيذ اللاحق في 16 أكتوبر أدناه اعتمد تنفيذ مساعد المواقع، مع إبقاء المنصات الاجتماعية مؤجلة.

## تحديث 16 أكتوبر 2026 — المرحلة الحالية

نُفّذ مساعد اقتراح إعداد المصدر واختباره من نموذج المصدر. خطوات الاستخدام والتشغيل والقيود في [SOURCE-SETUP.md](SOURCE-SETUP.md). يغطي صفحات HTML العامة والموصلات المدعومة حاليًا، ولا يضيف موصل RSS أو API عامًا بمجرد طلب AI لذلك.

## المرحلة الثانية المحفوظة — لا تنفيذ حاليًا

- إضافة روابط LinkedIn وTelegram وFacebook العامة من لوحة الإدارة.
- تحديد طريقة الوصول المناسبة لكل منصة: API رسمي أو RSS موثوق أو موصل خاص مسموح ومجرّب، وما يتطلب حسابًا أو موافقة أو مفاتيح إضافية.
- اختبار اكتشاف المنشورات والتنقل والتحديثات ومنع التكرار وحدود الطلبات قبل الحفظ والتفعيل.
- استخدام AI لفهم محتوى الفرصة ومكانها داخل فلسطين مع حفظ دليل المصدر، ثم تطبيق قواعد التحقق المعتادة؛ كون المنشور عامًا أو الجهة فلسطينية لا يكفي وحده لإثبات مكان الفرصة.
- توضيح الانقطاع أو الحماية أو نقص الصلاحيات دون تجاوزها أو اعتماد إعداد تخميني.
- تبقى روابط هذه المنصات غير مدعومة في مساعد المرحلة الحالية وتعرض رسالة توضح تأجيلها.
