# مساعد إعداد موقع مصدر جديد

## من لوحة الأدمن

1. افتح المصادر ← إضافة (أو تعديل مصدر موجود).
2. ضع رابط HTTPS عامًا في «مساعد إعداد المصدر»، واضغط «اقتراح الإعدادات واختبارها». الطلب صريح ويستهلك حتى طلبي AI؛ لا يعمل عند فتح الصفحة أو تلقائيًا.
3. يقرأ النظام الصفحة في متصفح معزول دون حساب مستخدم، ويرسل سياقًا محدودًا من النص وبنية الروابط إلى AI. يختار النموذج رابطًا موجودًا فعليًا في الصفحة، لا رابطًا مخمنًا. إذا اقترح صفحة قوائم مختلفة، يفتحها النظام ويطلب إعداداتها في الطلب الثاني.
4. يختبر النظام اكتشاف الروابط ويقرأ نص أول إعلان باستخدام قارئ المحتوى المعتاد. يعرض حتى عشرة روابط، ورابط التنقل التالي المرصود إن وجد، ونص عينة، والإعدادات. لا يحفظ إعلانات أو ينشئ SourceItems أو ينشر فرصًا أثناء المعاينة.
5. راجع الروابط والنص، ثم اضغط «تطبيق الاقتراح على الحقول». يملأ الرابط والموصل وConfigurationJson، واسم المصدر إن كان فارغًا. لا يغير موافقة الاستخدام أو التفعيل أو الجدول أو نسخة التزامن أو يحفظ النموذج.
6. راجع حقول المصدر وسجل الموافقة على الاستخدام ثم احفظ بنفسك. يبدأ الجمع المعتاد حسب الجدولة بعد تفعيل المصدر واعتماد استخدامه؛ إثبات المكان والتواريخ والنشر يبقى في خط المعالجة الحالي.

## ما تدعمه المرحلة الحالية

- موصل Automatic لصفحات HTML العامة، أو BrowserSelectors مع محددات CSS وروابط صفحات تالية مباشرة.
- تغذيتا JobsRss وReliefWebRss المعتمدتان بالفعل، بروابطهما الرسمية فقط. أي RSS/API آخر يحتاج موصلًا مجرّبًا؛ اقتراح النموذج وحده لا يضيف دعمًا في الكود.
- رفض رابط لم يُرصد في الصفحة أو خارج نطاق المضيف الأصلي. قد تحتاج إدخال الرابط النهائي يدويًا إذا كان الموقع يحوّل إلى مضيف آخر؛ لا يوسع المساعد AllowedHosts تلقائيًا.
- إظهار الفشل إذا لم تُكتشف روابط أو لم يكتمل نص العينة أو احتاجت الصفحات تسجيل دخول/حماية أو تنقلًا تفاعليًا غير مدعوم. نجاح العينة لا يثبت جميع الإعلانات أو اكتمال جميع الصفحات، ولم يتم اختبار اجتياز جميع صفحات المصدر.
- لا يغيّر البرومبت الفعّال لاستخراج الفرص. تعليماته المستقلة موجودة في `SourceSetupAssistant.Instructions`، وتتعامل مع بيانات الموقع كمحتوى غير موثوق.

## التشغيل المحلي والاستضافة

التحليل والمعاينة يعملان في عملية **Web** التي تستقبل طلب الأدمن، بينما الجمع المجدول يستمر في Worker كالمعتاد. يحتاج حساب Web:

- إعدادات `Ai:ApiKey` و`Ai:Model` صالحة في ملف إعداداته؛ قد تختلف عن إعدادات العامل.
- Chromium المتوافق مع Playwright وصلاحية تشغيله. يحدد `Browser:BrowsersPath` في appsettings.json مجلد المتصفحات، أو `Browser:ExecutablePath` ملف المتصفح مباشرةً. المسارات النسبية تُحسب من مجلد تشغيل التطبيق، ولا يحدد start-local.ps1 مسار المتصفح. لا يكفي أن يكون المتصفح متاحًا لحساب خدمة Worker وحده.
- اتصال HTTPS بالمصدر وبمزود AI. القراءة تستخدم سياسة النطاقات العامة الحالية وتمنع الروابط الخاصة وبيانات الدخول والمنافذ غير القياسية.
- إذا احتوت عينة الإعلان مرفق PDF يحتاج معالجة، يستخدم قارئ المحتوى أدوات PDF المتاحة **لحساب Web وإعداداته**؛ إذا لم تتوفر، يفشل الاختبار دون تغيير المصدر. يمكن اختيار صفحة HTML مناسبة أو إعداد أدوات المعاينة لذلك الحساب. تبقى الملفات المؤقتة محكومة بالتنظيف المعتاد.

مهلة العملية ثلاث دقائق، وطلب AI الواحد حتى 75 ثانية قبل وصول الاستجابة. راعِ حدود مهلة الطلب في الاستضافة/الوكيل. طلب واحد فقط من المساعد يعمل في نسخة Web الواحدة في الوقت نفسه؛ لا يعيد إرسال طلبات مدفوعة تلقائيًا. الحدود: سياق صفحة حتى 2 مليون حرف قبل الاختصار، حتى 200 رابط مرصود، نص حتى 12000 حرف، بنية HTML حتى 40000 حرف، استجابة مزود حتى 256KB، وروابط عينة حتى 10.

تسجل طلبات AI الخاصة بالإعداد في `Audit` تحت `Source.SetupAi` مع النموذج وبصمة التعليمات والمدة والحالة وأعداد التوكنز التي أعادها المزود؛ المجهول يبقى مجهولًا. هذا سجل مستقل عن إحصاءات **استخراج الفرص** في AiUsage حتى لا تُنسب تعليمات إعداد المصدر إلى نسخة برومبت استخراج لم تُستخدم. تسجل المعاينة الناجحة تحت `Source.SetupPreview`. لا تُسجل مفاتيح المزود أو نصوص الصفحات في هذه الإدخالات. لا تحتاج هذه الميزة مهاجرة جديدة.

## التحقق

```powershell
dotnet build HiringPs.sln -c Release
dotnet run --project tests/HiringPs.Checks -c Release -- --source-setup-check
```

الفحوص تستخدم صفحات واستجابات AI مصطنعة دون تكلفة أو كتابة قاعدة البيانات. تغطي الروابط المخترعة والخروج عن النطاق والمنصات المؤجلة والإعداد غير المدعوم وسير الطلبين واشتراط نجاح المعاينة. اختبار مزود AI فعلي وموقعك وSQL وحساب IIS يحتاج بيئتك؛ لا يثبت نجاح fixtures هذه الاتصالات.

المرحلة الثانية الخاصة بـLinkedIn وTelegram وFacebook محفوظة في [DEFERRED-SOURCE-AUTOMATION.md](DEFERRED-SOURCE-AUTOMATION.md) ولم تُنفّذ.
