# واجهات العضو والتفضيلات والمحفوظات

## حفظ الفرصة

- يرسل زر الحفظ POST عبر fetch مع رمز مكافحة التزوير، ثم يعرض «محفوظة» وأيقونة الصح دون تغيير الصفحة أو موضع المستخدم. يقرأ عرض القائمة والتفاصيل حالة الحفظ الخاصة بالعضو عند فتح الصفحة أيضًا.
- يمنع تكرار الإرسال أثناء الطلب، ويتحقق من نجاح الرد ومعرّف الفرصة قبل تغيير الزر. الفشل يعرض رسالة قابلة لإعادة المحاولة؛ لا يعيد POST تلقائيًا.
- يتحقق السيرفر من إتاحة الفرصة ويمنع ازدواج سجل العضو والفرصة، بما فيه الطلبات المتزامنة. دون JavaScript يعود المستخدم إلى الرابط المحلي المرسل بعد الحفظ.

## التفضيلات

- تظهر الفئات والأماكن المختارة كبطاقات صغيرة مع زر حذف. تظهر الخيارات المتاحة تحتها داخل قائمة قابلة للفتح والطي، مع زر صح للإضافة.
- تحفظ الإضافة والحذف وتغييرات أنواع الفرص والتذكير عبر fetch؛ تبقى حالة فتح القوائم محفوظة خلال تحديث النموذج. يبقى زر الحفظ والنموذج العادي متاحين دون JavaScript.
- يتيح النظام إزالة قيمة قديمة حتى لو اختفت من قائمة الخيارات الحالية، ويقبل إضافة القيم الموجودة في الكتالوج فقط. الاختيار الفارغ للمجال أو المكان يعني الجميع، كما كان سابقًا.
- يحتفظ الحفظ بتاريخ تغيير التفضيلات وقواعد التنبيهات الحالية؛ لا يعيد إرسال الفرص القديمة.

## لوحة العضو والمحفوظات والإعدادات

- بطاقات تنقل بأيقونات ووصف وحركة hover متوافقة مع هوية الموقع، مع احترام تفضيل تقليل الحركة. تعرض الباقة الفعالة حاليًا وعدد المحفوظات.
- تعرض المحفوظات بطاقات متجاوبة وأزرار تفاصيل وإزالة. الإزالة والتنقل يعملان عبر fetch مع ترقيم من السيرفر، 10 سجلات في الصفحة، وتصحيح الصفحة عند إزالة آخر سجل منها.
- لا يحذف العضو محفوظات عضو آخر. يبقى عرض التفاصيل خاضعًا لصلاحيات نوع الفرصة وحالتها، مع رسالة الاشتراك عند الحاجة.
- قسمت إعدادات الحساب إلى بيانات الحساب والتنبيهات والأمان. لم تتغير آلية ربط تليجرام أو التحقق أو تغيير كلمة المرور.

## الملفات الأساسية

- `wwwroot/js/member-actions.js`: تفاعلات الحفظ والتفضيلات والمحفوظات.
- `Views/Shared/_SaveOpportunityButton.cshtml`: زر الحفظ المشترك.
- `Areas/Member/Views/Preferences/_PreferenceEditor.cshtml` و`_PreferenceChoices.cshtml`: نموذج التفضيلات والبطاقات.
- `Areas/Member/Views/Saved/_SavedResults.cshtml`: نتائج المحفوظات وترقيمها.
- `wwwroot/css/site.css`: التنسيق المتجاوب وحالات hover والحركة المخففة.

## التحقق وحدوده

نجح بناء الويب ومشروع الفحوص و229 تحققًا محليًا. نجحت 25 حالة متصفح تشمل العربية والإنجليزية والهاتف وسطح المكتب، والحفظ دون انتقال، والتفضيلات والإزالة والترقيم وتقليل الحركة. تستخدم معاينة المتصفح واجهات Razor الحقيقية مع ردود تجريبية؛ لا تثبت اتصال قاعدة بيانات حية أو مزود خارجي.

أضيفت فحوص SQL اختيارية في `MemberWorkspaceSqlChecks` للحفظ المتزامن وملكية السجلات والتحقق من خيارات التفضيلات، لكنها لم تُشغّل لعدم توفر `HIRING_TEST_SQL`. لا تحتاج هذه الواجهات إلى Migration جديدة؛ مهاجرة الخصم لجميع الباقات موثقة بصورة مستقلة في `MEMBER-CHECKOUT.md`.
