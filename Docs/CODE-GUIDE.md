# دليل قراءة وتعديل المشروع

هذا الدليل يوضح أين يوجد كل جزء، ومن أين تبدأ عند تعديل الموقع.
التنسيق الحالي يفصل الكتل والتعليمات بدل وضع الصفحة أو الدالة كاملة في سطر واحد.
لم تتغير أسماء الحقول والمسارات أو طريقة عمل النظام ضمن مهمة ترتيب الملفات.

## ابدأ بهذه الملفات

1. `src/HiringPs.Web/Views/Shared/_Layout.cshtml`: الهيكل المشترك لكل الصفحات.
2. `src/HiringPs.Web/Views/Home/Index.cshtml`: صفحة الفرص والبحث والفلاتر.
3. `src/HiringPs.Web/wwwroot/css/site.css`: الألوان والمقاسات وتنسيق الهاتف.
4. `src/HiringPs.Web/Resources/Labels.resx`: النصوص العربية.
5. `src/HiringPs.Web/Controllers/HomeController.cs`: البيانات التي تصل لصفحات الزائر.

## كيف يصل الطلب إلى الصفحة؟

```text
المتصفح يطلب رابطًا
    ↓
Controller يستقبل الطلب ويقرأ البيانات
    ↓
Model يحمل البيانات المطلوبة
    ↓
View تعرض البيانات للمستخدم
    ↓
_Layout يضيف الهيدر والفوتر والملفات المشتركة
```

في Razor، `@` تعني بداية تعبير C#، و`@{ ... }` كتلة إعدادات الصفحة.
`@if` لشرط العرض، و`@foreach` لتكرار عنصر على مجموعة بيانات.
`Model` هو بيانات الصفحة، و`T["Key"]` يجلب النص من ملفات الترجمة.
`asp-controller` و`asp-action` ينشئان رابطًا أو يحددان وجهة النموذج.
التعليقات بين `@* ... *@` مخصصة للمطور ولا تظهر في الصفحة.

## النصوص واللغات

- `Resources/Labels.resx`: العربية الافتراضية.
- `Resources/Labels.en.resx`: الإنجليزية.
- المفتاح نفسه في الملفين؛ غيّر محتوى `<value>` عند تعديل نص.
- لا تغيّر اسم المفتاح إلا بعد تعديل كل موضع يستخدمه في الكود.
- النصوص المحفوظة في قاعدة البيانات، مثل محتوى «من نحن»، تُعدل من الإدارة.
- `Models/SiteFacts.cs`: نصوص أسئلة الموقع المشتركة بين العرض والبيانات المنظمة.
- بعض رسائل التشغيل وتعليمات نموذج الذكاء الاصطناعي داخل C# تبقى نصوصًا حرفية؛
  لم نغيّر مضمونها أو نترجمها ضمن التنسيق لأنها تؤثر في التشغيل والاستخراج.

دورة الإعلان المعتادة:

```text
مصدر مفعّل وموافق على استخدامه
    ↓
اكتشاف رابط الإعلان
    ↓
جلب المحتوى وحفظه
    ↓
استخراج حقول الإعلان بالنموذج
    ↓
فحص البيانات وأدلتها
    ↓
نشر / مراجعة / إعادة محاولة / أرشفة بحسب النتيجة
```

بعض الحالات الأساسية:

| الاسم في الكود | المعنى |
| --- | --- |
| `Discovered` | اكتُشف الرابط ولم يكتمل جمعه. |
| `AwaitingAi` | المحتوى متاح وينتظر الاستخراج. |
| `Retry` | ينتظر إعادة المحاولة بعد تعثر. |
| `NeedsReview` | يحتاج مراجعة الأدمن. |
| `Published` | منشور. |
| `Archived` | مؤرشف. |
| `AdminOverride` | قرار أدمن محفوظ يمنع استبداله بالاستخراج اللاحق. |

## العامل وسكربتات التشغيل

- `src/HiringPs.Worker/Program.cs`: تهيئة العامل وتحديد وضع تشغيله.
- `src/HiringPs.Worker/Worker.cs`: حلقة التشغيل في الخلفية.
- `scripts/start-local.ps1`: بدء الموقع ثم العامل وتتبع عملياتهما.
- `scripts/stop-local.ps1`: إيقاف العمليات التي بدأتها أدوات التشغيل فقط.
- `scripts/publish.ps1`: إخراج حزم النشر إلى مجلد محلي.
- `scripts/install-worker.ps1`: تثبيت خدمة Windows للعامل.
- `scripts/jobs-rss-check.ps1`: فحص موصل RSS.
- `tests/HiringPs.Checks/Program.cs`: الفحوص الموجودة؛ هذه المهمة رتبت الملف فقط.

## الإعدادات والملفات المولّدة

- ملفات `.csproj` تحدد الإطار والحزم ومراجع المشاريع.
- `Directory.Build.props` يحتوي إعدادات C# المشتركة.
- `NuGet.Config` يحدد مصدر الحزم، و`dotnet-tools.json` يحدد أداة EF.
- `appsettings.json` و`Properties/launchSettings.json` لإعدادات التطبيق والتشغيل.
- لا تضع كلمات المرور أو مفاتيح الخدمات داخل ملفات المشروع.
- `Migrations/` وملفات `.Designer.cs` و`HiringDbModelSnapshot.cs` مولدة بأدوات EF؛
  تركناها كما هي ضمن مهمة القراءة. كذلك لم نعد كتابة الصور أو ملفات build.
- `bin/` و`obj/` وملفات المتصفح والمكتبات الخارجية ليست ملفات تُعدل يدويًا.
- `.editorconfig` يحدد المسافات والأسطر للمحرر، و`.prettierrc.json` يحدد تنسيق الويب.

## التحقق من أن التنسيق لم يغير العمل

جرى بناء الحل، ومقارنة قيم رموز C# وكود Razor ونصوصه وعناصره قبل التنسيق وبعده،
ومقارنة قيم JSON والترجمات، والتحقق من تحليل ورموز سكربتات PowerShell.
لم تُشغّل سكربتات النشر أو التثبيت ولم تُعدّل قاعدة البيانات أو يُنشر الموقع.

للتشغيل والنشر راجع `LOCAL-RUN.md` و`MANUAL-DEPLOYMENT.md`.
لتهيئة محركات البحث راجع `SEO.md` و`GEO.md`.
تحسين قراءة PDF مؤجل وموثق في `PDF-TEXT.md`؛ التنسيق الحالي لا يفعّله.
