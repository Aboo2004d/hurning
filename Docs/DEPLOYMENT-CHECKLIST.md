# قائمة التحقق قبل رفع تحديث إلى السيرفر

اقرأها قبل كل رفع. الطريقة المعتمدة: `publish` على جهازك إلى `C:\ESD` (ملف النشر `FolderProfile`)، ثم نسخ **الملفات التي تغيّرت فقط** إلى مجلد الموقع على السيرفر.

## ممنوع

- **لا تحذف مجلد الموقع على السيرفر ولا تستبدله كاملًا**، ولا تنشر مباشرة إلى مجلد السيرفر بخيار «حذف الملفات الموجودة» (`DeleteExistingFiles`). هذا الخيار مفعّل في ملف النشر لأنه ينظف `C:\ESD` على جهازك فقط.
- **لا تحذف ولا تستبدل هذه المجلدات داخل مجلد الموقع على السيرفر**، فهي بيانات حية لا تأتي مع النشر:
  - `data\payment-evidence\` — إثباتات الدفع التي رفعها المشتركون. **ضياعها لا يُعوَّض.**
  - `data\pdf-work\` — عمل PDF المؤقت (صلاحية الكتابة عليه ضرورية).
  - `Data\CollectorDiagnostics\` — سجلات تشخيص الجمع.
  - `logs\` — السجلات ونصوص PDF المؤرشفة.
- **لا تستبدل `appsettings.json` على السيرفر بالنسخة المحلية دون مراجعة.** نسخة السيرفر فيها جملة اتصال الإنتاج ومفاتيح Gemini وتليجرام والدفع. إن أضاف التحديث مفاتيح جديدة، أضفها يدويًا إلى ملف السيرفر.
- **لا تحذف `C:\HiringRuntime`** — أدوات PDF (Poppler وTesseract) التي يستخدمها الموقع.

## قبل الرفع

- [ ] سحبت آخر نسخة من git وبُني الحل دون أخطاء.
- [ ] راجعت هل يحتوي التحديث على Migration جديدة (`src/HiringPs.Core/Migrations`). الموقع يطبقها تلقائيًا عند التشغيل؛ خذ نسخة احتياطية من قاعدة البيانات قبلها.
- [ ] راجعت هل أضاف التحديث مفاتيح إعدادات جديدة في `src/HiringPs.Web/appsettings.json` (قارنها بملف السيرفر) أو غيّر `appsettings.Production.json`.

## أثناء الرفع

- [ ] انسخ محتوى `C:\ESD` فوق مجلد الموقع (استبدال الملفات الموجودة، دون حذف ما ليس في النشر).
- [ ] لا تنسخ `appsettings.json` من `C:\ESD` إلا إن قررت ذلك عمدًا بعد المقارنة.
- [ ] `appsettings.Production.json` يُنسخ عادة (لا يحوي أسرارًا: Edge ومسار الأدوات).
- [ ] إن قفل IIS بعض ملفات DLL: ضع `app_offline.htm` في مجلد الموقع أثناء النسخ ثم احذفه، أو أوقف الـ Application Pool مؤقتًا.

## بعد الرفع

- [ ] افتح الموقع وتأكد أنه يعمل.
- [ ] لوحة الإدارة ← **الأدوات**: «فحص الآن» على المتصفح وأدوات PDF ومجلد PDF المؤقت واتصال AI؛ كلها «يعمل».
- [ ] لوحة الإدارة ← **المصادر**: آخر تشغيل لكل مصدر دون أخطاء.
- [ ] إن ظهرت مشكلة صلاحيات (مجلد PDF المؤقت أو المتصفح)، أعد تشغيل:
  `scripts\configure-iis-runtime.ps1 -SiteName "hiring.ps" -Recycle` (PowerShell كمسؤول).

## عند تحديث Poppler أو Tesseract أو Playwright

- شغّل `scripts\prepare-runtime.ps1` محليًا وانسخ `artifacts\runtime` فوق `C:\HiringRuntime`.
- ترقية حزمة `Microsoft.Playwright` قد تحتاج إصدار Edge أحدث على السيرفر؛ حدّث Edge وافحص المتصفح من صفحة الأدوات.

تفاصيل التشغيل كموقع واحد: [SINGLE-SITE-DEPLOYMENT.md](SINGLE-SITE-DEPLOYMENT.md).
