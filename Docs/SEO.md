# تهيئة محركات البحث — التوظيف في فلسطين

## ما ينفذه الموقع

- عنوان ووصف بحسب نوع الفرصة وصفحتها والجهة والمكان؛ لا تُضاف كلمات مفتاحية مخفية.
- روابط canonical ثابتة للنطاق الإنتاجي، دون الاعتماد على Host الوارد في الطلب.
- نسختان واضحتان للغة عبر `/ar` و`/en`، مع `hreflang` متبادل
  و`x-default` للعربية. يحافظ تبديل اللغة على الصفحة والفلاتر ويغيّر بادئة اللغة مع بقاء معاملات البحث والترقيم.
- وسوم Open Graph وTwitter مع الشعار الحالي، وعنوان ووصف ورابط الصفحة نفسها.
- بيانات JSON-LD: Organization وWebSite وWebPage/CollectionPage وBreadcrumbList
  وقائمة الفرص المعروضة فعلًا. تُسلسل النصوص بترميز JSON الافتراضي لمنع كسر عنصر script.
- canonical مستقل لكل صفحة نتائج مرقمة وروابط السابق/التالي؛ لا تُجمع كل الصفحات على الأولى.
- `noindex, follow` للبحث والفلاتر والأرشيف والنتائج الفارغة والإعلانات المنتهية،
  مع استبعادها من خريطة الموقع. لا تُحذف الإعلانات المنتهية أو تُعاد كأخطاء.
- صفحات الإدارة والحساب غير قابلة للفهرسة، مع `X-Robots-Tag` للاستجابات الخاصة
  والأخطاء، وإرشادات robots لمنع زحف الإدارة والحساب.
- ملف `/sitemap.xml` أصبح فهرس خرائط: `/sitemaps/pages.xml` للصفحات العامة والأنواع
  غير الفارغة، و`/sitemaps/opportunities-N.xml` للفرص المنشورة غير المنتهية.
  كل جزء يضم حتى 10,000 فرصة بنسختي اللغة، دون سقف إجمالي ثابت للفرص.
- لا يوضع lastmod بتاريخ فحص العامل، لأن التحقق من المصدر لا يثبت تغيير المحتوى.

## إعداد النطاق

الافتراضي `https://hiring.ps`. إذا اختلف النطاق النهائي، اضبط:

```text
Seo__PublicOrigin=https://example.com
```

يجب أن يكون أصل HTTPS فقط، دون مسار أو منفذ مخصص أو معاملات أو بيانات دخول.
أعد تشغيل التطبيق بعد تغييره. الرابط الأساسي وخريطة الموقع وبيانات المشاركة
تتبع الإعداد نفسه. اضبط لدى الاستضافة تحويلات 301 من HTTP ومن نسخ النطاق
الأخرى إلى النطاق المعتمد. هذا التغيير لا يضبط DNS أو IIS أو CDN نيابة عنك.
في بيئة اختبار عامة امنع الفهرسة على مستوى الاستضافة أو احمها بتسجيل دخول.

## حدود البيانات المنظمة

لا تُنشر بيانات JobPosting حاليًا: الصفحة تعرض ملخصًا لا الوصف الكامل، وبعض
البيانات الأساسية غير متاحة من المصدر. لا يجوز اختلاق تاريخ نشر أو عنوان تفصيلي
أو راتب أو نوع دوام، ولا وصف الموقع بأنه جهة توظيف. غياب موعد الإغلاق لا يمنع
نشر الإعلان، لكن الإعلان المؤرشف أو المنتهي يُزال من الخرائط ومن فهرسة الصفحات.
لإضافة JobPosting لاحقًا يلزم وصف وظيفي كامل ظاهر ومطابق للمصدر، وتاريخ نشر أصلي
موثوق، وبيانات مكان العمل، ومراجعة أهلية الصفحة وفق إرشادات Google الحالية.

## ما بعد النشر

1. تحقق من إعداد النطاق واستجابات HTTPS والروابط الأساسية في مصدر الصفحات.
2. أضف خاصية النطاق إلى Google Search Console وأكّد ملكيتها عبر DNS؛ لا تُحفظ
   رموز تحقق أو مفاتيح مفترضة في المستودع.
3. أرسل `/sitemap.xml`، وافحص صفحة رئيسية ونوع فرصة وتفاصيل إعلان بكلتا اللغتين.
4. استخدم Rich Results Test وSchema Markup Validator للتحقق من البيانات المنظمة،
   وافحص ظهور بطاقات المشاركة بأدوات الشبكات الاجتماعية.
5. راقب الفهرسة والصفحات المستبعدة وأخطاء الزحف ومؤشرات الأداء على الهاتف.
   صورة مشاركة مخصصة عالية الدقة تحسين لاحق؛ الإصدار الحالي يستخدم الشعار الفعلي.

التحقق الحالي يشمل نجاح البناء؛ لم يُنفذ فحص Google أو الزحف في الاستضافة.
هذه التهيئة لا تضمن ترتيبًا أو نتائج غنية؛ جودة المحتوى الأصلي واكتماله وسرعة
الموقع وإتاحة الصفحات لمحركات البحث تبقى عوامل لازمة.
