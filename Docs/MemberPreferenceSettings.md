# إعداد حد التفضيلات لغير المشتركين

من لوحة الإدارة افتح **المستخدمون/الأعضاء ← إعدادات التفضيلات**:

```text
/ar/Admin/PreferenceSettings
/en/Admin/PreferenceSettings
```

يمكن الوصول إليها أيضًا من صفحة رسائل الأعضاء والبحث عبر البوت.

- يحدد الإعداد الحد الأقصى لعدد **المجالات المفضلة** للحساب الذي لا يملك اشتراكًا ساريًا. لا يحد عدد المدن.
- القيمة الافتراضية 3، مع إمكانية اختيار عدد صحيح من 0 إلى 1000. الصفر يمنع اختيار المجالات للحسابات غير المشتركة.
- تحسب الأسماء داخل المجموعة المعتمدة مجالًا واحدًا وفق القواعد الحالية.
- الاشتراكات السارية تحتفظ بحدود نسخ باقاتها المشتراة، بما فيها الباقات غير المحدودة. الاشتراك المنتهي أو الملغى أو الذي لم يبدأ بعد لا يستثني الحساب من الحد المجاني الحالي.
- حفظ الإعداد يسجل المسؤول والقيمة السابقة والجديدة في التدقيق، ويطبق الحد في الخادم عند حفظ تفضيلات الأعضاء.
- خفض الحد لا يحذف اختيارات الأعضاء. يمكنهم إزالتها حتى يصبح العدد ضمن الحد، ولا يُسمح بحفظ عدد يتجاوزه. الاختيارات الفارغة لا تتحول إلى تنبيه لكل المجالات.

تضيف Migration `ConfigurableFreePreferenceLimit` جدول `MemberPreferenceSettings` مع قيد 0–1000، دون تعديل الاختيارات أو الباقات المحفوظة. يستخدم النظام القيمة الافتراضية 3 حتى يحفظ المسؤول قيمة أخرى. يطبّق Web التحديث بآلية ترحيل القاعدة الحالية عند بدء التشغيل.

تستخدم أزرار صفحات رسائل الأعضاء ومحرر التفضيلات وإعداد الحد أنماط الموقع المشتركة للألوان والأيقونات والأبعاد وحالات التعطيل، مع مراعاة اتجاه اللغة والوضع الليلي والهاتف.

فحوص معزولة:

```sh
dotnet run --project tests/HiringPs.Checks -- --free-preference-limit-check
dotnet run --project tests/HiringPs.Checks -- --preference-settings-ui-check
```

فحص الواجهة يستخدم Chromium محليًا وصفحات اختبار دون اتصال بقاعدة حقيقية أو تليجرام.
