# تشغيل Hiring.ps على جهازك
المسار: `F:\Uni\Files\Works\HiringPs`.

## ما بقي كما عدّلته أنت
إعداد اتصال قاعدة البيانات، `DesignTimeFactory.cs`، `SeedData.cs`، و`Program.cs` الخاص بالموقع لم تتغير. الموقع يشغّل `MigrateAsync()` ثم بياناتك الأولية تلقائيًا عند البدء، كما طلبت. لا نحذف قاعدة البيانات ولا نعيد إنشاءها في أدوات التشغيل.

## التشغيل المعتاد
1. تأكد أن SQL/LocalDB الذي ضبطته في اتصالك يعمل، وأن إعداد الاتصال متاح للموقع والعامل بنفس القيمة.
2. افتح PowerShell داخل مسار المشروع.
3. أول مرة أو بعد تحديث الحزم:

```powershell
dotnet restore HiringPs.sln --configfile NuGet.Config
dotnet tool restore
dotnet build HiringPs.sln -c Release -p:UseAppHost=false
$env:PLAYWRIGHT_BROWSERS_PATH="$PWD\.playwright-browsers"
dotnet src/HiringPs.Worker/bin/Release/net10.0/HiringPs.Worker.dll --install-browser
```

Chromium موجود محليًا بالفعل في `.playwright-browsers`؛ أمر التثبيت مطلوب إذا لم يوجد أو تغير إصدار Playwright.

4. شغّل الموقع والعامل معًا:

```powershell
.\scripts\start-local.ps1
```

الموقع: `http://127.0.0.1:5186`، الإدارة: `/Admin`. السكربت يبدأ الموقع أولًا وينتظر نجاح بدء المهاجرات والبيانات، ثم يشغّل العامل في الخلفية. سجلات كل عملية في `artifacts/local-logs`. لا يعرض كلمات مرور أو يغير الاتصال.

لإيقاف العمليات التي بدأها هذا السكربت فقط:

```powershell
.\scripts\stop-local.ps1
```

إذا كان الموقع يعمل من Visual Studio، أوقفه أولًا أو اختر منفذًا مختلفًا: `start-local.ps1 -Port 5190`. لا يحاول السكربت إنهاء عمليات Visual Studio أو خدمات مستخدم أخرى.

## تشغيل منفصل من طرفيتين

```powershell
# الأولى
dotnet run --project src/HiringPs.Web --no-launch-profile -p:UseAppHost=false -- --environment Development --urls http://127.0.0.1:5186

# الثانية، بعد أن يعمل الموقع وينتهي تطبيق المهاجرات
$env:DOTNET_ENVIRONMENT="Development"
$env:PLAYWRIGHT_BROWSERS_PATH="$PWD\.playwright-browsers"
dotnet run --project src/HiringPs.Worker --no-launch-profile -p:UseAppHost=false
```

تشغيل الويب وحده لا يشغّل عامل الجمع المستقل. محليًا يجب أن يبقى العامل يعمل، وعلى السيرفر Windows Service يتولى ذلك تلقائيًا.

## إدارة الجمع
- فعّل المصدر واضبط موصله وسجّل استخدامه بعد مراجعته.
- «ساعة بدء الجمع» بتوقيت فلسطين. 00:00 مع كل 24 ساعة تعني منتصف الليل يوميًا، و00:00 مع كل 8 ساعات تعني 00:00 ثم 08:00 ثم 16:00.
- الحساب ثابت من نقطة البداية المحلية؛ طول الجولة لا يؤخر الساعة التالية. تغيير الساعة أو الدورية يعيد حساب الموعد القادم، ولا يحذف بيانات المصدر.
- زر «ابدأ الجمع الآن» لكل صف يطلب ذلك المصدر وحده؛ العامل يفحص الطلبات كل 5 ثوانٍ افتراضيًا. إذا كان مشغولًا بجولة ينتظر الطلب نهايتها، فلا تبدأ جولتان متداخلتان.
- الطلبات محفوظة في SQL، والضغط المتكرر لا يكدّس طلبات للمصدر نفسه. القائمة تتحدث أثناء الانتظار/التنفيذ.
- الجمع اليدوي لا يحرك موعدًا دوريًا مستقبليًا؛ إذا فات الموعد، يتقدم إلى الموعد الصحيح التالي من نقطة البداية.
- عند خطأ مصدر تُسجل المشكلة ويعاد المحاولة دون تحويل الإعلان إلى «منتهٍ».

## مفتاح AI
المفتاح غير موجود حتى الآن. لإكمال التصنيف والنشر الآلي ضعه في User Secrets المشتركة؛ لا ترسله بالمحادثة ولا تكتبه في Git:

```powershell
dotnet user-secrets set "Ai:ApiKey" "YOUR_PRIVATE_KEY" --project src/HiringPs.Web
dotnet user-secrets set "Ai:Model" "gemini-2.5-flash-lite" --project src/HiringPs.Web
```

عند غيابه/نفاد الحصة: يحفظ المحتوى في الانتظار ويعيد المحاولة تلقائيًا، ولا ينشر نتائج مخمنة. الحالات الملتبسة ومرفقات الصور غير المقروءة تحتاج مراجعة الأدمن كما اتفقنا.

## التحقق قبل النشر

```powershell
dotnet run --project tests/HiringPs.Checks -c Release
```

الاختبارات تستخدم قاعدة SQL Express مؤقتة مستقلة باسم HiringPs_Checks_GUID، وتحذف هذه القاعدة وحدها. لا تغيّر اتصال جهازك أو قاعدة التطبيق. اختبارات UI في scripts تقرأ بيانات الأدمن المحلي للاختبار دون عرضها، وتترك سجلاتها التوضيحية مخفية.

لا يعتبر نجاح اللوكال دليلًا على صلاحيات/HTTPS/SQL/الجمع من IP السيرفر، ولا يغني عن اختبار نموذج AI فعليًا.

### إضافة مصدر دون إعداد CSS
من لوحة المصادر اختر إضافة؛ الخيار الافتراضي Automatic. أدخل رابط صفحة قائمة الوظائف/التدريب/العطاءات، الاسم وموافقة الاستخدام والدورية. اترك الإعدادات المتقدمة {}. بعد الحفظ اضغط ابدأ الجمع الآن. عند غموض الاكتشاف يظهر سبب الفشل في حالة المصدر؛ ذلك يحتاج مراجعة تقنية بدل نشر تخمين. يبقى استخراج الإعلان عبر Gemini بانتظار المفتاح إن لم يضف.
