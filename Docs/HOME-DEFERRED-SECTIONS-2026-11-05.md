# التحميل التدريجي للرئيسية وفحص AI

المسار: PalestinianJobs-Planning-github/Hire.

تعرض الاستجابة الأولى الفرص والفلاتر وصلاحيات العرض الأساسية، دون استعلامات الإحصاءات أو الوظائف القريبة من الإغلاق أو بيانات المدن والجهات. بعد window.load يطلب المتصفح الإحصاءات ثم الإغلاق. يراقب اقتراب موضعي المدن والجهات من مجال الرؤية ويجلبهما تباعًا. شروط ظهور الأقسام في البحث والأرشيف والترقيم محفوظة.

لكل قسم زر تحديث ومؤشر تحميل وخطأ وإعادة محاولة داخل مساحته. التحديث اليدوي يتجاوز كاش الصفحة ويجدد كاش بيانات القسم؛ إعادة محاولة تحديث فاشل تحافظ على هذا السلوك. لا يعاد تحميل الفرص أو الصفحة.

فحص AI كان يفرض 60 ثانية بينما AiExtractor يستخدم Ai:TimeoutSeconds (افتراضي 180، ضمن 30–300). يستخدم الاثنان الآن دالة واحدة، ويتميز انتهاء المهلة عن عطل الشبكة برسالة AiCheckTimeout. طول الطلب على السيرفر لا يمكن تفسيره من استثناء الإلغاء وحده؛ يلزم إعادة فحص على السيرفر بعد تحديث العامل. لا تستخدم هذه النتيجة لإثبات نجاح الاتصال الفعلي بالمزوّد.

الفحوص:

- dotnet run --project tests/HiringPs.HomeSections.Checks — 11 حالة خلفية ناجحة على SQLite، دون الاتصال بقاعدة المشروع أو Gemini.
- node tests/home-sections.check.cjs — تسلسل الطلبات والتأجيل وفشل قسم والتحديث وإعادة محاولته ومنع تكرار الطلب الجاري.
- خادم الفحص --serve على 127.0.0.1:5487 يعرض بيانات صناعية مؤقتة؛ تحقق HTTP بالعربية والإنجليزية والبحث والأرشيف والأقسام الأربعة.
- نجح بناء الويب. تعذر فحص المتصفح بصريًا لعدم اتصال أداة المتصفح.

تطبيق التعديل على الاستضافة يتطلب نشر الويب وملفات js/css والعامل ثم إعادة تشغيلهما. لا توجد migration أو تعديلات على بيانات الاتصال.
