- النطاق: hiring.ps. الاسم التجاري مؤجل.
- الإعلانات والملخصات بلغتها الأصلية؛ واجهة عربية وإنجليزية؛ حد الملخص 200 حرف.
- لا بيانات أو كلمات مرور أو مفاتيح افتراضية للإنتاج. استخدم User Secrets محليًا والمتغيرات البيئية على VPS.

المشروع قيد التنفيذ ولم يُنشر. واجهة MVC والإدارة والقاعدة والعامل موجودة، ونتائج التحقق والقيود موثقة منفصلة في Docs.
