# مفاتيح الحماية في القاعدة فقط

الويب والعامل يستخدمان `dbo.DataProtectionKeys` عبر اتصال `ConnectionStrings:Hiring`
واسم تطبيق ثابت `HiringPs`. لا توجد قراءة أو كتابة لمجلد مفاتيح، ولا استيراد أو بحث
عن مفاتيح قديمة، ولا تراجع إلى مخزن ملفات أو مفاتيح مؤقتة عند تعطل SQL. إعداد
`DataProtection:KeyPath` القديم لم يعد يستخدم ويمكن إزالته من الإعدادات.

إطار ASP.NET ينشئ المفاتيح عند الحاجة إذا كان الجدول فارغًا، ويجددها تلقائيًا.
تبقى المفاتيح السابقة الموجودة في القاعدة لفك البيانات بعد التدوير. إعادة التشغيل
أو فقد مجلد النشر لا يمحو المفاتيح، بشرط بقاء القاعدة. حذف القاعدة أو استعادة نسخة
لا تحتوي المفاتيح المطلوبة قد يفقد القدرة على فك البيانات المحمية.

## النشر

طبّق الماجريشن `20261021170000_DatabaseProtectionKeys` ثم أعد تشغيل الويب والعامل
بالنسخة الجديدة، مع توجيههما لنفس القاعدة. الويب يطبق الماجريشنز عند البدء؛ يجب أن
يكتمل ذلك قبل بدء العامل، أو طبّقها بأداة EF المعتادة. الماجريشن ينشئ الجدول فقط.
يحتاج حساب التشغيل SELECT وINSERT على جدول المفاتيح، ولا يحتاج صلاحيات ملفات
أو إنشاء جداول أثناء الاستخدام المعتاد.

بناء على قرار بدء مخزن جديد دون استيراد المفاتيح القديمة: تنتهي الجلسات السابقة
وقد تحتاج إعادة ربط منصات النشر والخدمات التي حُميت بياناتها بالمفاتيح القديمة.
لا يغير التعديل سجلات الربط القديمة أو يمحوها، لكنه لا يستطيع فكها بمفتاح جديد.
لا يتم تعطيل حماية النماذج أو تجاهل فشل فك البيانات.

## حماية المخزن

XML يحتوي مادة مفاتيح حساسة، ولا يضاف إلى سجل العمليات أو صفحة أخطاء النظام ولا
يُعرض في لوحة الإدارة. لا يشفّر هذا التغيير XML بشهادة إضافية تتطلب ملفًا أو مفتاحًا
خارجيًا، ولا يعتمد على Windows DPAPI الخاص بحساب الويب؛ لذلك احمِ صلاحيات القاعدة
والنسخ الاحتياطية واستخدم تشفير التخزين المتاح لدى الاستضافة. لا تشارك عمود Xml.
لفحص وجود المفاتيح دون كشفها:

```sql
SELECT COUNT_BIG(*) AS KeyCount FROM dbo.DataProtectionKeys;
SELECT TOP (10) Id, FriendlyName,
       CreatedAt AT TIME ZONE 'West Bank Standard Time' AS [وقت فلسطين]
FROM dbo.DataProtectionKeys ORDER BY Id DESC;
```

هذا يزيل الاعتماد على صلاحيات ملفات مفاتيح ASP.NET؛ لا يثبت أن مشكلة 500 السابقة
سببها المفاتيح، ولا يعالج أخطاء الاتصال بالقاعدة أو نقص صلاحياتها. إذا تعطلت القاعدة
فلن يتجاوز النظام حماية الجلسات أو النماذج؛ راجع الاستثناء لتشخيص السبب.
